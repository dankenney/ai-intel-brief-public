# AI Intel Brief: public weekly notes

Weekly, general-audience notes on applied AI for people who build things: coding agents and harnesses, evals and verification, agent security, personal agents, agent-first software design, voice/video/creative tools, and physical AI.

Each week has two files:

- **ten-things.md**: ten concrete things to try, some practical and some deliberately unconventional. Each one has its sources, a verification status, and a build brief you can paste into Codex or Claude Code (goal, constraints, acceptance criteria, first steps).
- **library-highlights.md**: short, source-checked notes added to the library that week.

**Verification status:** ✅ primary source fetched and the claim matches · 🟡 source exists, claim partly checked · ⚠️ unverified · 🧪 deliberately unconventional idea.

Papers are summarised from their abstracts unless noted. Benchmarks and vendor claims are reported as stated by their authors. Check the sources before you rely on anything here. This is not legal, financial or security advice.

This repo is produced by an automated research pipeline with human review. Every external link was fetched and logged before publication, and every file passes an automated privacy scan before it is committed.
