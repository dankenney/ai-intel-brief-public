# Library highlights: 2026-W44

Source-checked notes added to the library this week (✅ primary source checked · 🟡 partly checked).

## Security

- **hashcat 8.0: PCFG attack mode, hash recipes and FPGA support** ✅: The biggest hashcat release so far adds a grammar-based mode that tries the likeliest passwords first and can take hints about a target, hash recipes for custom constructions, FPGA bcrypt support and 146 new modes. Passwords built from personal details are now cheaper to guess. ([source](https://github.com/hashcat/hashcat/releases/tag/v8.0.0))
- **Gheist: stolen GitHub tokens plant workflows that print every Actions secret** ✅: Wiz found over 13,500 throwaway ci-sync branches from 850+ accounts, each committing a sync-check workflow that base32-encodes env and secrets past log masking, downloads the log and deletes the run. GitHub's approval hold covers public repos only, so private repos and Enterprise Server ran the payload. Rotate secrets before deleting branches. ([source](https://www.wiz.io/blog/gheist-attempted-scaled-abuse-of-stolen-github-tokens-stumbles))
- **What GitHub's pull_request_target change on Dec 2 still leaves open** ✅: Public repos without an event policy lose pull_request_target from Dec 2, but checkout actions pinned by SHA to pre-fix versions miss the new protections, issue_comment and repository_dispatch triggers are not covered, and script injection plus artifact poisoning still work. ([source](https://www.wiz.io/blog/github-actions-security-pwn-request-reckoning))
- **Brotli CVE-2026-111497: patched Node is not the end of it** ✅: Fixing Node fixes only Node. Compiled Bun executables need rebuilding after Bun 1.4.4, Go binaries need a rebuild on a fixed toolchain, and Python requests decodes Brotli whenever brotli or brotlicffi is installed. CISA added the bug to KEV on Oct 27. ([source](https://socket.dev/blog/emudhra-brotli-security-fix))
- **Brotli exploit works in practice against Express 5 and Electron** ✅: Trail of Bits got code execution in lab setups; Semgrep explains the reachable paths: Express 5 with body-parser 2.x decompresses br request bodies, and Node's built-in fetch decompresses br responses. Fixed in Node 22.23.4, 24.22.1 and 26.12.1. ([source](https://semgrep.dev/blog/2026/patch-your-node-and-eat-your-brotli-or-you-wont-get-dessert/))
- **Trail of Bits brotli-checker: a coding-agent skill that finds vulnerable decoder copies** ✅: A Claude Code and Codex skill that searches a codebase and its dependencies for vendored Brotli decoders affected by CVE-2026-111497. Read it before installing, as with any third-party skill. ([source](https://github.com/trailofbits/brotli-checker))
- **Fake wallet extensions served a clean config during store review and a stealer after** ✅: Socket found Firefox add-ons whose server returned an inactive config while Mozilla reviewed them, then switched live. Two also carried a CLAUDE.md jailbreak file the extension never loads, apparently aimed at AI-assisted reviewers. A one-time review proves nothing about code fetched at runtime. ([source](https://socket.dev/blog/firefox-wallet-impersonators))
- **Searchjacked: 319 extensions with no special permissions reroute search** ✅: About 13 million users had extensions that swap the default search engine for an operator server that resells queries. Several asked for no permissions at all, so a clean permission list is not evidence of a safe extension. ([source](https://socket.dev/blog/searchjacked))
- **Linux kernel CVE-2026-46300 on CISA KEV, chained with PHP2Shell** ✅: A socket-buffer bug lets an unprivileged user write into root-owned files and is being chained with the PHP2Shell web bugs. Fixed in 5.10.257, 5.15.208, 6.1.174, 6.6.141 and later stable kernels; check hosted boxes against the list. ([source](https://www.cisa.gov/news-events/alerts/2026/10/28/cisa-adds-two-known-exploited-vulnerabilities-catalog))
- **Agentic intrusions: attackers now let agents write and retry the tooling** ✅: Wiz describes intrusions where agents write custom tools, test them and retry at machine speed while a person only sets goals, including the ARTEX framework. The upside for defenders is that these runs are noisy. ([source](https://www.wiz.io/blog/the-rise-of-agentic-attacks))
- **Tampered Claude Code extension served from Cursor's marketplace for 11 hours** ✅: Versions 2.1.312 and 2.1.313 for macOS and Windows, not built by Anthropic, sent host details out, added an svc-telemetry SSH key, tried to open a reverse tunnel and set up persistence. Uninstalling is not enough; check authorized_keys, launch agents and cron, and rotate credentials from a clean machine. ([source](https://cursor.com/blog/claude-code-extension-security-notice))
- **A publisher name on a listing is not provenance** ✅: Socket checked npm, Open VSX and the VS Code Marketplace and found no publication record for the bad 2.1.313 build, which pinned it to Cursor's own marketplace. Verify an extension against the vendor's real release channel rather than the name on the listing. ([source](https://socket.dev/blog/claude-code-extension-compromise))
- **Noma's indicator list for the fake Claude Code extension** ✅: Concrete indicators to grep for: the callback IP, the extension.js hash, a hidden .smt config file, a fake sysmond launch agent and a Linux reboot cron entry. ([source](https://noma.security/blog/supply-chain-attack-poisoned-claude-code-extension-installs-hidden-backdoors))
- **Socket Threat Intel shows per-campaign impact: blocked, detected or not detected** ✅: Each malware campaign now links to the repos, branches, scans and firewall events where the package appeared, which turns 'were we hit?' after an npm or PyPI incident into a lookup. ([source](https://socket.dev/blog/threat-intel-campaign-impact))

## Coding agents & tooling

- **GPT-6.1 Terra: computer use at half the price of the previous Terra** 🟡: In Codex and the API at 1 dollar input and 5 dollars output per million tokens with a 1.05M context. Tools need the Responses API. OpenAI's own benchmark claims were not independently checked, and OpenAI still points complex coding at Sol or Astra. ([source](https://developers.openai.com/api/docs/models/gpt-6.1-terra))
- **Codex memory: choose the extraction and consolidation models** 🟡: Codex exposes memories.extract_model and memories.consolidation_model, which belong under a [memories] table with memories enabled under [features]. Posts that give the keys without the table headers produce a config that silently does nothing. ([source](https://learn.chatgpt.com/docs/config-file/config-reference))
- **GitHub Copilot Fusion: per-prompt routing with Single, Cascade and Critique** ✅: You pick an effort level and Fusion picks one model, a cheap draft plus judge escalation, or parallel critics plus a revision. Artificial Analysis measured about half the cost of Claude Code on Opus for 2 points less, but intermediate drafts are hidden from you. ([source](https://docs.github.com/en/copilot/concepts/models/copilot-fusion))
- **Claude API request limit rises to 128 MB** ✅: Messages and Token Counting accept up to 128 MB, up from 32 MB, mainly for screenshot-heavy computer-use runs and large PDFs. Batch stays 256 MB, Files 500 MB, PDFs 600 pages. Over-limit requests still return 413. ([source](https://platform.claude.com/docs/en/api/errors))
- **Mistral Large 4 open weights: 1T total, 52B active, 1M context** 🟡: MoE model in FP8 and NVFP4 for vLLM or SGLang under an MIT-based licence that needs a separate licence to resell as a hosted service. Self-hosting needs a multi-GPU server; the coding and security gains are Mistral's own numbers. ([source](https://mistral.ai/news/mistral-large-4-oss/))
- **Google shuts down Jules and folds it into Antigravity** ✅: Sessions can run until Nov 11, then Jules is read-only, and it closes on Dec 31. A reminder to keep agent task history exportable rather than locked in one vendor's background agent. ([source](https://jules.google/docs/changelog/2026-10-29/))
- **GitHub Agentic Workflows GA: Markdown automations compiled to Actions** ✅: Write triage, CI analysis or doc updates in Markdown; it compiles to ordinary Actions YAML with read-only agent permissions, a firewalled sandbox, a safe-outputs gate and a separate threat-detection job. GA adds cost forecasts, per-workflow model routing and micro-VM isolation. ([source](https://github.blog/changelog/2026-10-28-github-agentic-workflows-generally-available/))

## Evals & verification

- **Epoch AI's benchmarking hub as an outside check on public benchmark scores** 🟡: Epoch tracks 94 benchmarks across 411 models and rolls them into one capabilities index, run independently of the labs. Useful when a vendor number looks too good, though the quality problems inside individual benchmarks still need reading the benchmark's own paper. ([source](https://epoch.ai/benchmarks/))
- **Intelligence Index v5: 60% private tests and a merge-or-zero coding benchmark** ✅: Artificial Analysis rebuilt its index so most of it rests on private or held-out tests, and added FrontierCode 2.0, where a task scores zero if any blocking check a maintainer would apply fails. Private sets resist contamination but cannot be audited from outside. ([source](https://artificialanalysis.ai/articles/artificial-analysis-intelligence-index-v5))
- **Evals for AI Engineers: Shankar and Husain's short book on error analysis and judges** ✅: Covers error analysis, synthetic test data, code-based checks, LLM judges and production monitoring, kept deliberately short. A good shared reference for anyone building workflow evals. ([source](https://ai-evals.com/))

## Agent-first design

- **OpenUI Lang: a streaming UI language limited to components you register** 🟡: OpenUI has the model write a compact UI language instead of JSON, generated from a Zod-defined component library and rendered as it streams in React, Vue, Svelte or Angular. The model can only place registered components. The headline 67% token saving is the best single case; the project's own seven-scenario total is about 52%. ([source](https://github.com/thesysdev/openui))
- **KRAKEN: one command registry for CLI, MCP, GUI and agents, with additive-only agent writes** ✅: A reverse-engineering workbench whose design is the useful part: a single registry drives every interface so they cannot drift, every edit is attributed and undoable, agent writes are additive and capped per run, and anything read from the analysed binary is passed to the model as untrusted data. Young repo, so copy the pattern rather than install it blindly. ([source](https://github.com/adam-atlassoftware/kraken))
- **Five rules for lists of AI-written text: lead with the difference** ✅: For sidebars of session titles, notification digests or dashboard summary columns: open with the subject or verb, put the distinguishing words first, keep one structure and one term per concept, vary only when it means something, and match verb tone to the page. Each rule cites reading research and comes with a before and after. ([source](https://fsdatalab.github.io/blog/agent-text-at-scale/))
- **Programmatic tool calling: the model writes one script that runs many tool calls** ✅: In Droid 1.0 the model writes a sandboxed JavaScript program that fans out calls in parallel, loops, and checks results in code; the model sees only the script's printed output. Factory's Linear cleanup made 312 calls in 2 model requests and about 61k tokens. Because the checks are code, the model can't skip a step by losing track. ([source](https://factory.com/news/frontier-harness))

## Voice, video, creativity, animation

- **Code2Video-AA: pairwise judged benchmark for motion graphics written as code** ✅: 27 models each write one HTML plus GSAP file per brief across 114 briefs; a single judge model compares pairs blind on engagement, prompt intent, composition, temporal consistency and craft. The five axes double as a rubric for any code-to-video QA step. One judge model means one model's taste. ([source](https://artificialanalysis.ai/evaluations/code2video-aa))
- **ElevenLabs Cue: character-level forced alignment in 90+ languages** ✅: Give it audio plus text and it returns start and end times for every character and word, with a reported 179 ms mean error on full recordings. Useful for captions, lip sync and cutting video on the word. The comparison is the vendor's own. ([source](https://elevenlabs.io/blog/cue-aligner))
- **ffmpeg-skill: 42 local FFmpeg tools for coding agents over MCP** 🟡: Exposes cutting, captions, reframing, loudness and platform exports to Claude Code, Cursor or Codex with no cloud and no API keys. New third-party code; only the description was checked. ([source](https://github.com/kajisho5/ffmpeg-skill))
